# 야생 건축물 → RPG 월드 이전 가이드 (26.1.2 Fabric → 1.21.1 NeoForge)

> 목적: 기존 야생 월드(26.1.2)에서 이룬 **주거지/건축물**만 새 RPG 월드(1.21.1 NeoForge)로 옮기고,
> 그 외 지형은 RPG 팩 구조물과 함께 **새로 생성**한다.
> ⚠️ 이 작업은 **수동·인게임·운영자 진행** 영역이다(자동화 불가). 아래는 방법과 한계를 정직하게 정리한 것.

## 0. 핵심 제약 (먼저 이해할 것)

1. **버전 다운그레이드라 월드 직접 복사 불가.** 26.1.2 세이브는 1.21.1 에서 열 수 없다(마크는 상위→하위
   호환 안 됨). `world/` 폴더 복사는 작동하지 않는다.
2. **로더도 다르다(Fabric → NeoForge).** 모드 블록·아이템의 등록 ID 체계가 달라 NBT 직접 이식도 불가.
3. **블록 집합 불일치 → 일부 블록 소실.** 1.21.1 이후 추가된 블록(구리 골렘 시대 1.21.9+, 26.x 신규
   블록 등)은 1.21.1 에 **존재하지 않는다** → 붙여넣을 때 누락되거나 대체된다. (구리골렘 자동분류기
   기능은 이미 RPG 팩의 **Refined Storage** 로 대체하기로 합의됨 — 블록 자체는 못 옮겨도 기능은 재현.)
4. 따라서 옮길 수 있는 건 **블록 구조(형태)** 위주다. 모드 전용 아이템이 든 상자 내용물, 일부
   타일엔티티 NBT, 엔티티(아머스탠드/액자 내용) 등은 보존이 보장되지 않는다.

## 1. 이전 방법: 스키매틱(청사진) 내보내기 → 가져오기

직접 복사가 안 되므로, 건축물 영역을 **청사진 파일로 추출**해 새 월드에 **붙여넣는다**.

1. (26.1.2 쪽) 클라이언트에 스키매틱 모드를 넣고 옮길 건물 영역을 선택해 `.litematic`(또는 `.schem`)으로 저장.
2. (1.21.1 RPG 쪽) 같은 계열 모드로 그 청사진을 불러와 새 월드의 원하는 위치에 붙여넣기(creative/OP 권장).
3. 누락 블록은 수동 보정. 대규모면 영역을 나눠 반복.

### ⚠️ 미확정 — 도구 가용성(사용자 환경에서 확인 필요)

26.1.2 는 **출시 직후 최신 버전(calendar versioning)** 이라, 스키매틱 도구(Litematica / WorldEdit 등)가
**26.1.2 빌드를 아직 제공하지 않을 가능성이 크다.** 이 단계는 다음을 직접 확인해야 진행 가능:

- [ ] 26.1.2 Fabric 에서 동작하는 스키매틱 export 도구가 실제로 존재하는가? (Modrinth 에서 26.1.2 대응
      버전 확인)
- [ ] 1.21.1 NeoForge 에서 동작하는 동일 포맷 import 도구가 존재하는가?
- 둘 중 하나라도 26.1.2 대응이 없으면, 26.1.2 가 해당 도구를 지원할 때까지 **대기**하거나, 아래 대안을 검토.

> 도구 가용성을 확인하지 않은 채 "이 모드로 옮기면 됩니다"라고 단정하지 않는다 — 26.1.2 의 최신성 때문에
> 실패할 수 있는 단계다. 실제 Modrinth 버전 확인 후 절차를 확정할 것.

## 2. 대안 (스키매틱 도구가 26.1.2 를 지원하지 않을 때)

- **A. 수동 재건축**: 핵심 주거지만 새 RPG 월드에 직접 다시 짓는다(소실 0, 노동 ↑). 규모가 작으면 가장 확실.
- **B. 대기**: 스키매틱 도구가 26.1.2 를 지원할 때까지 야생 월드를 보존하고, RPG 월드는 신규 건축으로 먼저 시작.
- **C. 야생은 야생대로 유지**: 26.1.2 정식/베타 채널 서버를 그대로 두고, RPG 는 완전 신규 월드로 분리 운영
  (이전 자체를 하지 않음). 런처가 이미 채널을 분리하므로 두 월드 병행이 가능.

## 3. 보존되지 않는 것(이전 시 손실 목록 — 기대치 관리)

- 1.21.1 에 없는 블록(구리골렘 시대 등) — 누락/대체.
- 모드 전용 아이템이 든 컨테이너 내용물(Fabric 팩 ↔ NeoForge 팩 모드 구성이 다름).
- 레드스톤 회로 중 버전 의존 동작, 일부 타일엔티티 NBT.
- 엔티티(주민·아머스탠드·길들인 동물 등)는 청사진 방식으로는 일반적으로 미포함.

## 4. 진행 전 결정 사항(사용자)

- [ ] **이전 범위**: 어떤 건축물을 옮길지(주거지 전체 / 핵심 건물만).
- [ ] **방법 선택**: §1 스키매틱(도구 확인 후) / §2-A 수동 재건축 / §2-B 대기 / §2-C 분리 운영.
- [ ] **야생 월드 운명**: 이전 후 보존할지(병행 운영) / 동결할지.

> 결론: **이전은 "버전 다운그레이드 + 로더 변경"이라 직접 복사가 불가능하고, 26.1.2 스키매틱 도구 가용성이
> 핵심 변수다.** 도구 확인이 끝나기 전에는 §2-C(분리 운영)로 RPG 신규 월드를 먼저 시작하는 것이 가장
> 안전하다 — 런처 채널이 이미 분리돼 있어 야생/RPG 병행에 추가 작업이 없다.
