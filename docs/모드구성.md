## 3. packwiz 구성 명령 (서버 박스 / 팩 메인테이너용)

```bash
# 0) 팩 초기화 (Fabric + MC 26.1.2; loader 버전은 최신 stable 자동/선택)
packwiz init   # name, MC=26.1.2, loader=fabric 선택

# 1) 요청 모드 + 코어 (packwiz가 의존 라이브러리 자동 추가 프롬프트)
packwiz modrinth add sodium
packwiz modrinth add lithium
packwiz modrinth add ferrite-core
packwiz modrinth add entityculling
packwiz modrinth add immediatelyfast
packwiz modrinth add sodium-extra
packwiz modrinth add reeses-sodium-options
packwiz modrinth add iris
packwiz modrinth add entitytexturefeatures
packwiz modrinth add entity-model-features
packwiz modrinth add lambdynamiclights
packwiz modrinth add simple-voice-chat
packwiz modrinth add sound-physics-remastered
packwiz modrinth add xaeros-minimap
packwiz modrinth add xaeros-world-map
packwiz modrinth add enchantment-descriptions
packwiz modrinth add clumps
packwiz modrinth add animal_feeding_trough
packwiz modrinth add rightclickharvest

# 2) 추가 추천 편의 (취향껏 trim)
packwiz modrinth add modmenu
packwiz modrinth add appleskin
packwiz modrinth add jade
packwiz modrinth add mouse-tweaks
packwiz modrinth add controlling
packwiz modrinth add zoomify
# (선택) packwiz modrinth add koreanify chat-heads dynamic-fps

# 3) 리소스팩 (모드 아님)
packwiz modrinth add fresh-animations
packwiz modrinth add fresh-animations-extensions
packwiz modrinth add complementary-reimagined   # 셰이더팩

# 4) side 수동 감사 (★자동 감지 불완전 — 반드시 확인)
#   both : fabric-api, simple-voice-chat, lithium, ferrite-core, clumps, animal_feeding_trough
#   server: rightclickharvest, jamlib (+ architectury-api 가 required면)
#   client: 위 외 전부 + appleskin + 리소스팩
#   → packwiz modrinth add 에는 --side 플래그가 없다. 각 mods/<slug>.pw.toml 의 [side] 값을 위 분류대로 직접 편집/확인 (자동감지는 Modrinth 메타 의존이라 부정확)

# 5) 인덱스 갱신 후 커밋 (CI/pre-commit에 refresh 권장)
packwiz refresh
git add . && git commit -m "modpack: 26.1.2 initial set" && git push
```

> **side 자동감지 주의:** packwiz가 Modrinth 메타로 side를 추정하나 부정확하다. 특히 **Simple Voice Chat=both**(서버 없으면 음성 0), **Fabric API=both**, **Lithium/FerriteCore=both**(서버 최적화), **RightClickHarvest=server**를 반드시 확인. 잘못되면 서버가 모드를 못 받아 접속 거부/기능 누락.

## 4. 검증 메모 (착수 시 재확인)

- Sodium/Iris는 **버전 잠금 쌍** — 각 Iris 릴리스가 요구하는 정확한 Sodium 빌드를 함께 pin(예: Iris `1.10.9+26.1` ↔ Sodium `mc26.1.1-0.8.9`). packwiz가 26.1.2 호환 파일을 고르는지 확인.
- Sodium/Sodium Extra의 26.1.2 파일은 `26.1.x` range 태깅일 수 있음 — `packwiz add` 시 26.1.2에 매칭되는 정확 파일인지 확인.
- Fresh Animations 리소스팩은 로더 무관이나 **ETF/EMF가 26.1.2 빌드**여야 동작.
- 셰이더 사용 시 GPU 부하↑ — 저사양 친구는 Iris에서 셰이더 OFF로 바닐라+Sodium 성능 유지 가능.
- 서버 `server.properties`: `online-mode=true`(실 MS 인증). Simple Voice Chat 위해 **UDP 24454 개방**.

## 5. 비개발자 첫 실행 체크리스트 (Codex HIGH — 런처가 자동화할 항목)

> packwiz는 리소스팩/셰이더팩을 **다운로드만** 하고 **자동 활성화하지 않는다**. 비개발자 친구는 수동 활성화를 모를 수 있으므로, **런처가 첫 실행 시 `options.txt`를 미리 세팅**하거나 아래를 1회 안내한다.

- [ ] **리소스팩 활성화 + 순서** — `options.txt`의 `resourcePacks`에 `Fresh Animations: Extensions`를 **Fresh Animations보다 위(앞)** 로 배치(extensions가 위에 있어야 동작). 런처가 기본 `options.txt`를 주입하면 친구는 무조작.
- [ ] **셰이더 선택** — Iris 셰이더 메뉴에서 `Complementary Reimagined` 선택(저사양 친구는 셰이더 OFF로 바닐라+Sodium 성능). 런처가 기본 셰이더를 지정하거나 안내.
- [ ] **동적조명 중복 방지** — 셰이더 ON일 때 Complementary가 자체 핸드헬드 라이팅을 제공하면 LambDynamicLights와 이중 적용될 수 있다. 둘 중 하나만(셰이더 설정 또는 LDL 설정에서 끔). 기본값을 README에 명시.
- [ ] **음성채팅 동작 확인(서버)** — (1) 서버 로그 `Voicechat server started on port 24454`, (2) 방화벽/NAT **UDP 24454 인바운드** 룰, (3) 클라 SVC 상태 아이콘 초록. MC는 접속되는데 음성만 조용히 실패하는 경우 대부분 UDP 미개방.
- [ ] **macOS arm64 Java 25** — 첫 실행 시 CmlLib가 `mac-os-arm64` Java 25 런타임을 받는지 실기 확인(구현계획 M2-5).

> **셰이더 ON 스모크 테스트**: 셰이더 켠 상태에서 HUD/채팅/표지판/인벤토리/F3 텍스트가 정상 렌더되는지 1회 확인(ImmediatelyFast×Iris 상호작용).
