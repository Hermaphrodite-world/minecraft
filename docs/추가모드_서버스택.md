## 1. 서버 "플러그인" 대체 — 핵심 결론

**Fabric은 Bukkit/Spigot/Paper 플러그인을 못 돌린다.** 대신 아래 Fabric **서버 모드**가 1:1 대체한다. 대부분 `side=server`라 **친구는 바닐라 클라 그대로 접속**(서버에만 설치).

| 필요 기능 | Fabric 모드 | slug | side | 대체하는 Bukkit 플러그인 |
|-----------|-------------|------|------|--------------------------|
| 권한/그룹 | **LuckPerms** | `luckperms` | server | LuckPerms / PermissionsEx / GroupManager |
| 홈/워프/tpa/back/스폰/rtp | **WarpUtils** | `warputils` | server | EssentialsX (텔레포트) / HuskHomes |
| 채팅·접속/퇴장·사망 메시지 | **Styled Chat** | `styled-chat` | server | EssentialsX Chat / VentureChat + JoinMessage |
| (올인원 대안) 채팅+MOTD+afk+휴대GUI | Fuji | `fuji` | server | EssentialsX / CMI |
| 키트 지급 | Starter Kit *(+Collective 의존)* | `starter-kit` | server | EssentialsX Kits |
| **폭발 방지** ★ | **Blastproof** | `blastproof` | server | WorldGuard(폭발 플래그) |
| 땅 클레임/그리핑 방지 | **Open Parties and Claims** | `open-parties-and-claims` | both | GriefPrevention / WorldGuard 지역 |
| 블록 로깅·롤백 | **Ledger** | `ledger` | server | CoreProtect |
| 자동 백업 | **Fastback** (git 증분) | `fastback` | server | 백업 스크립트 / Textile·Simple Backups |
| 청크 사전생성 | **Chunky** | `chunky` | server | Chunky |
| 성능 프로파일러 | **spark** | `spark` | server | spark / timings |
| 네트워크 최적화 | **Krypton** | `krypton` | server | (Paper 내장 대체) |
| 동적 틱/엔티티 최적화 | **ServerCore** | `servercore` | server | Paper config |
| 멀티스레드 조명 | **ScalableLux** | `scalablelux` | server | (Starlight류) |
| 웹 지도 | **squaremap** | `squaremap` | server | Dynmap / squaremap |
| 경제(선택) | Savs Common Economy | `savs-common-economy` | server | EssentialsX Economy + Vault |

> **채팅 중복 주의:** **Styled Chat** 와 **Fuji 의 Chat 모듈**은 역할이 겹친다 — **하나만** 켤 것. 권장 조합: `WarpUtils(텔레포트) + Styled Chat(채팅)`. 더 통합을 원하면 Fuji 단독(Chat 모듈 ON, WarpUtils와 텔레포트 명령 중복은 모듈 단위로 한쪽만).

> **권한 백본:** LuckPerms를 먼저 깔면 WarpUtils/Styled Chat/Fuji 등이 그 권한 노드를 읽어 통합된다. 친구 서버라도 `default` 그룹에 명령 권한 한 줄씩 주는 방식이 깔끔.

## 2. ★ 폭발 방지 (사용자 핵심 요청) — Blastproof

**Blastproof** (`blastproof`, server-only, 26.1.2 Fabric stable 확인 — 정확 버전 문자열은 `packwiz add`가 자동 선택). 친구 클라는 무설치.

- **동작:** 폭발이 **블록을 파괴하는 것만 차단**, **엔티티/플레이어 피해는 유지** → 크리퍼·몹이 여전히 위협적이라 바닐라 느낌 보존.
- **소스별 토글** (`config/blastproof.json` 첫 실행 시 생성): TNT · 크리퍼 · 엔드크리스탈 · 위더 스컬 · 가스트/블레이즈 화염구 · 위더 본체 · 침대/리스폰앵커(other) · 커스텀.
- **권장 기본값(바닐라를 즐겁게):**
  - 크리퍼 block-damage = **OFF** (가장 흔한 지형 그리핑 차단)
  - TNT block-damage = **OFF** (실수/장난 폭파 방지)
  - 엔드크리스탈·위더 = **ON 유지** (보스/엔드 메커니즘 보존)
  - 침대/리스폰앵커(네더/엔드) = 취향껏

**왜 gamerule이 아니라 모드?** 바닐라 `mobGriefing` gamerule은 all-or-nothing이라 크리퍼만 끄려 해도 **농부 주민의 작물 심기·엔더맨 블록 줍기까지 같이 꺼진다.** 게다가 gamerule은 **TNT(플레이어 점화)·엔드크리스탈을 아예 통제 못 함.** 소스별 토글되는 Blastproof가 우월.

**보조:** Open Parties and Claims는 **클레임된 청크 안**의 폭발 그리핑도 막지만 클레임 영역에만 적용. **전역 지형 보호 = Blastproof**, **개인 땅 소유권 = OPAC** 으로 병행.

> 대안 **Creeper Healing**(폭발 후 지형 자동 복구, 가장 바닐라스러움)은 현재 **26.1.2 미지원**(1.21.11까지) — 포팅되면 재평가.

## 5. 주의 (착수 시)

- **동반 라이브러리 필수**(누락 시 크래시): Cloth Config(Falling Leaves/BetterF3/Screencopy), CreativeCore(AmbientSounds), YACL(Better Clouds/Auto Reconnect), Fabric Language Kotlin+libIPN(IPN), Collective(Starter Kit). packwiz가 보통 의존성을 자동 추가하나 프롬프트 확인.
- **beta 채널 허용 필요**: Open Parties and Claims(사실상 release 채널·16M+ DL이나 메타가 beta), Sit!의 OtterLib, Visuality, Trade Cycling, Savs Economy, Pl3xMap. `packwiz`가 release만 고르면 이들은 beta 버전 명시 선택.
- **side 필수**: Nature's/Explorer's Compass·Ultimate Map Atlases·Visible Traders는 `server_side=required` → **서버에도 같은 버전** 설치(친구 클라 단독 불가). Blastproof·WarpUtils·Ledger 등 관리 모드는 server-only라 친구 무설치.
- **채팅 중복**: Styled Chat ↔ Fuji Chat 모듈 — 하나만.
- **웹 지도**: squaremap은 내장 웹서버 포트 개방 필요(방화벽 확인). Dynmap은 26.1.2 미지원이라 squaremap 권장.
- **Better Clouds**: Iris/Complementary 셰이더와 구름 중복 → 셰이더 OFF 프리셋용·기본 OFF 권장.
- **미검증**: 전 판정은 Modrinth 메타(live API) 기반, 실 게임 런타임 미실행. Bobby 캐싱 회귀(#445), OPAC beta 안정성, RRV/IPN 실동작은 **서버 적용 전 테스트** 권장. (Codex는 학습 컷오프 이후 버전이라 일부를 "확인 불가"로 표기했으나, 본 판정은 워크플로의 live Modrinth API 조회 결과이므로 `packwiz add` 실행 시 실제 파일 존재로 최종 확인.)

## 6. 서버 보안 · 초기 설정 (Codex HIGH — 비개발자 서버 필수)

> 모드만으론 부족하다. 친구(지인) 서버라도 아래 최소 설정을 **서버 첫 기동 전/후** 잡아야 한다.

### 6.1 `server.properties` 필수
```properties
online-mode=true          # 실 MS 인증 (정품 검증, 도용 차단). 런처가 MS 로그인 쓰므로 필수
white-list=true           # 화이트리스트로 친구만 입장
enforce-whitelist=true    # 런타임에도 화이트리스트 강제
# 음성: Simple Voice Chat UDP 24454 (server.properties 아님, 방화벽에서 개방)
# view-distance=8~10       # 소규모 서버 RAM 절약
```
- 화이트리스트 추가: 콘솔 `whitelist add <닉네임>` → `whitelist reload`. **OP는 최소화**(운영자 본인만 `op <닉>`).
- RCON 쓸 거면 `enable-rcon=true` + **강한 `rcon.password`** + 포트는 **외부 비공개**(LAN/방화벽 한정).

### 6.2 LuckPerms 기본 그룹 권한 (예시)
LuckPerms를 먼저 깔고, `default` 그룹에 친구가 쓸 명령만 화이트리스트:
```
# 콘솔/인게임(OP)에서
lp group default permission set warputils.command.home true
lp group default permission set warputils.command.sethome true
lp group default permission set warputils.command.tpa true
lp group default permission set warputils.command.spawn true
lp group default permission set blastproof.* false      # 폭발설정은 운영자만
# (정확한 권한 노드는 각 모드 문서/첫 실행 config에서 확인)
```
> 권한 노드 이름은 모드별로 다르다 — 각 모드의 README/첫 실행 로그에서 실제 노드 확인 후 적용.

### 6.3 Open Parties and Claims(OPAC) 초기 설정
- 서버 정지 후 `config/openpartiesandclaims/` config 편집: **클레임 한도**(인당 청크 수), 클레임 내 **폭발/불 번짐/컨테이너/문/상인/가축 보호** 토글.
- 전역 지형은 **Blastproof**로, 개인 땅은 **OPAC 클레임**으로 — 역할 분리(§2).
- 친구에게 `/claim`(청크 클레임)·`/trust <닉>`(친구 허용) 사용법 1회 안내. Xaero 맵에 클레임이 표시됨.

### 6.4 squaremap 웹 지도 노출
- 내장 웹서버 **포트(기본 8080)** 사용. **외부 공개 시** 방화벽 인바운드 규칙 + (원하면) 리버스 프록시.
- 지인만 보게 하려면 **LAN 전용**(외부 포트 미개방)으로 운영.

### 6.5 위험 기본값 주의
- **백업 복구 테스트**: Fastback 백업을 한 번 실제 복원해 봐야 진짜 백업임(미테스트 백업 = 백업 아님).
- `/back`·RTP 남용, Starter Kit 리셋 동작, 경제 관리자 명령은 권한으로 제한.
