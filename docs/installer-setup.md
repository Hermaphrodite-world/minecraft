# 공식 런처 설치 가이드 (정품 로그인 · 승인 대기 없이)

> Herma Launcher에는 두 가지 플레이 방법이 있습니다. 이 문서는 **공식 마인크래프트 런처에 모드팩을 설치**하는 방법입니다.

## 두 방법 비교

| 방법 | 로그인 | 장점 | 비고 |
|------|--------|------|------|
| **① HermaLauncher 직접 Play** | **온라인(MS 정품)** | 원클릭, 자동 서버 접속·리소스팩·쉐이더 | v0.1.5+ 온라인 전용 (MS 승인 완료) |
| **② 공식 런처에 설치** (이 문서) | **공식 런처의 정품 로그인** | **승인 대기 없이 정품 즉시**, 익숙한 공식 런처 | 공식 런처에서 프로필 선택 한 번 |

> **왜 ②가 승인 대기가 없나?** 공식 마인크래프트 런처는 Mojang/Microsoft **자체** 인증을 씁니다. 우리가 별도 Azure 앱이나 Mojang 승인을 받을 필요가 전혀 없어요. 그래서 정품(온라인) 플레이가 **지금 즉시** 됩니다.

## 사용법 (3단계)

### 1. 공식 마인크래프트 런처를 완전히 종료
열려 있으면 프로필 저장이 안 됩니다. **완전히 종료**해 주세요(트레이/Dock 포함).

### 2. HermaLauncher에서 "공식 마인크래프트 런처에 설치" 버튼 클릭
- Fabric 로더 + 게임 파일 + 모드팩이 자동으로 공식 `.minecraft`에 설치됩니다.
- 모드는 바닐라와 섞이지 않게 **전용 폴더(`.minecraft/herma`)**에 들어갑니다 — 기존 바닐라 플레이에 영향 없음.
- "완료!" 메시지가 뜨면 끝.

### 3. 공식 런처 열기 → 프로필 선택 → 플레이
1. 공식 마인크래프트 런처 실행 → 정품 계정 로그인(이미 돼 있으면 생략).
2. 좌하단 **플레이 버튼 옆 프로필 드롭다운**에서 **"Hermaphrodite World"** 선택.
3. **플레이** → 모드팩이 적용된 게임 실행.
4. 멀티플레이 → 서버 추가: **(서버 주소는 메인테이너에게)** → 접속.

## 자주 묻는 것

**기존 공식 런처 프로필/계정이 사라지나요?**
아니요. 설치 도구는 기존 프로필·설정·로그인 정보를 **그대로 보존**하고 "Hermaphrodite World" 프로필만 **추가**합니다(검증 완료).

**바닐라 세계가 모드 때문에 깨지나요?**
아니요. 모드는 전용 폴더 `.minecraft/herma`에만 설치돼 바닐라 프로필과 분리됩니다.

**"공식 런처를 찾지 못했어요"가 떠요.**
[minecraft.net](https://www.minecraft.net/download)에서 공식 런처를 설치하고 **한 번 실행**한 뒤(.minecraft 폴더 생성됨) 다시 시도하세요.

**"공식 런처가 실행 중이라 저장할 수 없어요"가 떠요.**
공식 런처를 완전히 종료(트레이/Dock 포함)하고 다시 누르세요.

**모드팩이 업데이트되면?**
HermaLauncher에서 "공식 런처에 설치"를 다시 누르면 됩니다(프로필은 재사용, 모드만 갱신).

## macOS도 동일
공식 런처 위치만 다를 뿐(`~/Library/Application Support/minecraft`) 같은 버튼·같은 흐름입니다.
