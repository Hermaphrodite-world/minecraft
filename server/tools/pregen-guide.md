# 청크 사전생성(Pre-generation) 가이드 — 탐험 렉 해소

worldgen 모드(terralith·tectonic·wilderwild·promenade·구조물들)가 많아져, 플레이어가 **새 지역을 탐험할 때 서버가 실시간으로 청크를 생성하느라 렉**이 걸립니다. **미리 청크를 다 만들어두면**(pre-gen) 탐험 시 실시간 생성이 없어 매끄럽습니다.

팩에 **Chunky**(`chunky`) + **c2me**(멀티스레드 청크생성)가 들어있어 그대로 쓰면 됩니다.

---

## 0. 핵심
- **서버를 끌 필요 없습니다.** 켜진 상태(플레이어 접속 중에도 OK)에서 콘솔에 명령만 입력 → 백그라운드로 생성.
- 단 **CPU를 많이 씁니다** → 사람 적은 시간대 권장. 렉 생기면 `chunky pause`.
- 한 번 생성해두면 그 영역은 다시 안 만들어 영구히 매끄럽습니다.

## 1. 명령 (서버 콘솔 또는 OP가 게임 채팅에서 `/chunky ...`)
```
chunky center 730 2600     # 생성 중심 (X Z). 거점 근처 권장 (현재 거점 ≈ 730, 2600)
chunky radius 2500         # 반경(블록). 2500 = 약 5000×5000 영역
chunky shape square        # square(사각, 기본) 또는 circle
chunky start               # 시작! 진행률/ETA 가 콘솔에 표시됨
```
- 상태 확인: `chunky`  (진행률·속도·ETA)
- 일시정지/재개: `chunky pause` / `chunky continue`
- 취소: `chunky cancel`
- 다른 차원도: `chunky world minecraft:the_nether` → `chunky start` (네더는 반경 작게, 예: 1000)

## 2. 권장 값
| 상황 | center | radius | 비고 |
|---|---|---|---|
| 거점 주변 우선 | `730 2600` | `2000` | 빠르게 끝남, 거점 일대 매끈 |
| 넉넉히 | `730 2600` | `3500` | 탐험 여유, 시간/디스크 더 듬 |
| 스폰(0,0)도 | `0 0` | `1500` | 별도로 한 번 더 |

> 반경↑ = 생성 시간·디스크↑. 처음엔 2000으로 돌려보고 부족하면 늘리세요.
> (참고: 청크 1개 ≈ 16블록. radius 2500 = 약 98,000 청크 → 장비/부하에 따라 수십 분~수 시간.)

## 3. 순서 (권장)
1. 사람 적은 시간에 서버 콘솔에서 위 `chunky center/radius/start`.
2. `chunky` 로 진행률 확인. 서버 렉 심하면 `chunky pause` 후 더 한가할 때 `chunky continue`.
3. `Task finished` 뜨면 완료. 이후 그 영역 탐험은 실시간 생성 없이 매끄러움.

## 4. 같이 하면 좋은 것
- **클라 캐시**: 런처 v1.2.1+ 가 stale `.bobby` 캐시를 1회 자동 정리(경계 팝인 해소). 플레이어는 런처 자동 업데이트만 받으면 됨.
- **새 월드 권장 영역**: worldgen 변경분은 새/미생성 청크에만 적용 → pre-gen은 그 "새 지역"을 미리 만들어두는 것. 기존 거점은 그대로.

## 5. 주의
- pre-gen 중 `chunky cancel` 안 하고 서버 재시작하면, Chunky가 다음 부팅 때 이어서 진행할 수 있음(설정에 따라). 멈추려면 `chunky cancel`.
- 디스크 여유 확인(대량 청크 = region 파일 증가).
